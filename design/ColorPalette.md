# Color Palette

## Purpose

Define an initial color strategy for player identity, resource readability, and app UI.

## Goals

- Support quick player recognition.
- Keep resource categories distinguishable.
- Maintain accessibility on mobile screens.
- Avoid a one-note palette.

## Initial UI Palette Direction

- Background: warm off-white or deep neutral depending on theme mode.
- Surface: slightly raised neutral panels.
- Text: high-contrast charcoal or near-white.
- Accent: restrained green or gold for primary action.
- Danger: red for destructive actions and severe penalties.
- Info: blue for history and guidance.

## Player Colors

Use a curated set with labels and non-color identifiers:

- White.
- Orange.
- Blue.
- Red.

Each player color should have accessible foreground and background combinations.

## Resource Colors

Resource colors should be distinct from player colors where possible. Resource icons or labels should always accompany color.
