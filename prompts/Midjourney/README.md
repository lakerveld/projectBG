# Midjourney Prompts

Use this folder for visual exploration prompts if generated imagery becomes useful.

Recommended prompt categories:

- Mood exploration.
- Original resource icon concepts.
- Background texture studies.
- App store visual direction.

Generated assets must be reviewed before product use and should not imitate protected board game artwork.
